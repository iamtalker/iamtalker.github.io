# 0. 읽기 전에

- **근거**: 위키에 있는 타인의 글과 고전. 현대
  수련서([단전호흡](단전호흡)(이규행),
  [민족비전_정신수련법](민족비전_정신수련법)(봉우 권태훈의
  호흡법·수련문답), [단학요결](단학요결),
  [단전호흡_소주천_대주천_요점정리](단전호흡_소주천_대주천_요점정리)(현암),
  [금단의_길](금단의_길), [한단회](한단회), [포기천](포기천)), 중국
  기공서 번역([선도내공술](선도내공술), [생활기공](생활기공),
  [의수](의수), [내호흡](내호흡), [조식](조식), [잠호흡](잠호흡)),
  고전([용호비결](용호비결), [수진비록](수진비록), [삼법회통](삼법회통),
  [태을금화종지](태을금화종지), [성명규지](성명규지),
  [금선증론](금선증론), [천선정리](천선정리), [혜명경](혜명경),
  [활인심방](활인심방) 등), 비교용으로
  [월창거사](월창거사)·[안반수의로_얻는_깨달음의_세계](안반수의로_얻는_깨달음의_세계)·[고엔카](고엔카)·[하타요가프라디피카](하타요가프라디피카)를
  읽었다. 직접 쓴 글(일지·메모)은 근거에서 뺐다.
- **읽은 범위**: 호흡·단전을 다루는 문서 약 60개. 분량이 큰
  책(선도내공술·생활기공·민족비전·방도어록·금단의 길)과
  고전(태을금화종지·금선증론·성명규지 등)은 호흡·단전이 나오는 대목을
  골라 읽었고, 짧은 문서와 단전호흡 소개서는 전부 읽었다.
  [단전호흡](단전호흡)과 [단전_호흡과_정신문화](단전_호흡과_정신문화)는
  같은 책의 사본이다. 읽지 못한 것: 태을금화종지의 다른 버전(67만 자),
  [단수련법](단수련법), [북창내단사상연구](북창내단사상연구)의 본문(요약
  대목만 확인). 이전에 쓴 [단학_수행서](/claude_편집자/단학_수행서)는
  그대로 두었다.
- **범위**: 자세·호흡·마음 쓰기, 숨의 길이를 늘리는 법, 몸의 신호,
  소주천 입구까지. 대약·도태·출신 같은 뒤 단계는 고전의 서술이 있을 뿐
  이 자료만으로 확인할 수 없어 다루지 않는다.
- **표기**: 자료마다 말이 다른 곳은 “자료마다 다르다”고 적고 11장에
  모았다. “(제안)”은 자료에 없는 이 글의 정리다.
- **건강**: 의학 조언이 아니다. 지병이 있거나 수련 중 이상 반응이 심하면
  멈추고 진료를 받는다. (7장)
