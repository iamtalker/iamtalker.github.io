# 3.3 때와 곳

- 매일 **같은 시간**에. 새벽이 좋다는 서술이 있다(단학요결은 인시 3~5시,
  [조식](조식) 문서는 해 뜰 무렵, 삼법회통은 새벽빛이 훤할 때). 현암은
  몸과 마음이 가장 고요한 때를 권한다.
- 통풍이 되고 공기가 맑은 곳. 담배 연기와 먼지는 피한다. 식후 바로는
  피한다(선도내공술의 11주의).
- 길게 하는 것보다 **끊기지 않는 것**이 낫다는 말이 여러 곳에 있다.
