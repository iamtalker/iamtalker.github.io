# 7.1 괜찮은 신호

- 아랫배에서 배가 꾸르륵거리고 우레 같은 소리, 가슴이 번거로이 차거나
  뱃속이 아프다가 무언가 내려가는 느낌. 용호비결·수진비록·봉우가 “제대로
  되어 가는 징조”라 한다.
- 아랫배·손발이 따뜻해짐. 침이 고임(삼킨다). 트림·방귀·설사, 몸살,
  일시적 마른기침 같은 명현(현암).
- 초보자가 서늘함을 느끼는 것은 양기가 음기를 밀어내는 과정이라는
  설명(현암).
- 대부분 저절로 지나가므로 걱정하지 않는다.
