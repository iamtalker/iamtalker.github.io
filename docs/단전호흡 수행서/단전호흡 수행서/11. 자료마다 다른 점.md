# 11. 자료마다 다른 점

| 항목 | 갈리는 의견 |
|----|----|
| 눈 | 반개(용호비결·단학요결·태을금화종지) / 가볍게 감음, 모나리자 미소(이규행) / 상이 많이 보이면 반개(현암) |
| 단전 위치 | 2.1의 표. 1치 3푼, 2치 4푼, 3치, 전칠후삼, 배꼽 |
| 단전에 뜻 두기 | 은은히 둔다(용호비결·현암·이규행) / 처음엔 코끝의 빛(선도내공술) / 규를 지키지 않음(방도어록의 구양경여 소개) / 의수는 곁길(응신입기혈) |
| 배의 움직임 | 순호흡 기본(대다수) / 역호흡 보조(중국 기공 교재·포기천) / 봉우는 역호흡이 길이는 빨리 늘리나 정신이 밝아지지 않는다고 함 |
| 입문 호흡 | 토납 먼저, 조식은 나중(이규행) / 묵좌·자연호흡 후 조식(봉우·단학요결) |
| 숨 멈춤 | 금함(이규행·봉우·단학요결·선도내공술) / 막힌 혈에 한시적 지식 허용(현암) / 핵심 기법(요가) / 일부 고전은 올릴 때·내릴 때 정지(혜명경) |
| 폐기의 풀이 | 숨을 멈추지 않고 기운이 머묾(용호비결 주해·이규행) / 호흡을 멈추고 기를 축적(북창내단사상연구 요약 서술) |
| 축기 | 기를 쌓아 뭉침(일부 지도자) → 이규행은 오류라 함. 기초를 쌓는 것(이규행의 해석, 낙육당어록) / 백일축기(현암·한단회) / 폐기와 같음(단학요결) |
| 들숨·날숨의 비율 | 같게(봉우·단학요결·삼법회통·용호비결 해석본) / 많이 들어가고 적게 나오게(고상옥황심인경 주해) / 들어올 때 짧고 나갈 때 길게(안반수의 해설) / 고혈압은 날숨을 길게(생활기공) / 들숨·날숨 중 짧은 쪽에 맞추라(단학요결) |
| 호흡 길이 | 조식 20~40초·1분(봉우·단학요결) / 분당 6~8회(생활기공) |
| 눈으로 기 부리기 | 눈이 가는 곳에 기가 감(용호비결 폐기, 수진비록) — 단, 조식이 1분 이상 된 뒤에만(용호비결 주해). 초심자 금지 |
| 정자세 | 궤좌(무릎 꿇기, 이규행) / 가부좌·평좌 중 편한 것(대다수) |
| 수련 이름 | 단학 vs 단전호흡: 단학요결 저자는 조식·폐기 중심을 “단학”, 지식·폐식·의식으로 기를 돌리는 쪽을 “단전호흡”이라 구분. 위키의 다른 문서는 둘을 같은 말로 씀 |

이 차이는 **출발점(어느 유파·시대의 서술인가)** 에서 온다. 입문자는
대체로 “힘 빼기, 코로, 소리 없이, 고르게, 여유 남기기, 멈추지 않기”에서
만난다.
