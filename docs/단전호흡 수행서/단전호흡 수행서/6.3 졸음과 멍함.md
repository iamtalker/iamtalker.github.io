# 6.3 졸음과 멍함

- 졸리면 억지로 하지 말고 푹 잔 뒤 한다. 수련 중 잠드는 습관이 들면
  고치기 어렵다(현암).
- 봉우: 호흡에 재미를 붙이면 잠이 안 오고, 숨이 짧으면 피로해서 졸린다.
  졸릴 때 눕지 말고 몸을 푼 뒤 다시 한다.
- 졸림을 정(定)으로 착각하지 않는다. 생각이 아주 없는 멍함은
  무기공(無記空)이라 하여 금한다(현암).
