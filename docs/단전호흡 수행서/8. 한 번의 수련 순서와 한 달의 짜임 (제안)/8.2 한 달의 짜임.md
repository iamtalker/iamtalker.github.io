# 8.2 한 달의 짜임

| 기간 | 중점 | 확인 |
|----|----|----|
| 1~2주 | 자세 잡기, 묵좌식상, 숨결 고르기. 숫자 목표 없음. | 앉아 있어도 아프거나 졸리지 않다 |
| 3~4주 | 조식 시작. 들숨·날숨 3초 안팎에서 시작해 편하면 늘린다. 단전에 뜻을 은은히. | 같은 길이로 소리 없이 이어진다 |
| 2~3개월 | 하루도 거르지 않는다. 한 호흡 줄이기(유기)를 시도. 지도자나 자료로 점검. | 아랫배가 따뜻하고 숨이 편하다 |
| 이후 | 불씨·소주천 단계. 이때부터 **반드시 점검** | 7장의 신호가 없다 |

**매일 점검**

- 오늘 억지로 했는가? 숨을 참았는가?
- 숨이 소리 나지 않았는가? 들숨과 날숨 길이가 같았는가?
- 머리·얼굴이 뜨거워졌는가?
- 상이나 소리를 쫓았는가?
- 마무리(봉고)로 끝냈는가?
