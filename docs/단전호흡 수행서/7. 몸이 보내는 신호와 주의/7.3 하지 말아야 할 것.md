# 7.3 하지 말아야 할 것

1.  억지로 하지 않는다. 호흡도 자세도 기를 돌리는 것도.
2.  숨을 참거나 닫지 않는다(5장).
3.  **의식을 위로 올리지 않는다.** 이규행은 바른 지침 없이 상단전 수련을
    하는 것은 금기라 하고, 현암은 상을 보려 상단전에 의식을 올리면
    단전에 모은 기가 소모된다고 한다. 응신입기혈도 잡념이 분분한 채
    조규·단전 같은 특정 규를 의수하면 두통·어지럼·주화입마가 온다고
    경고한다.
4.  상(象)·소리·빛을 쫓지 않는다. 이규행은 기감에 흥분하는 것, 기의
    엑스터시에 빠지는 것이 두 번의 함정이라 한다. 방도어록과 현암:
    보이는 것을 들여다보지 말고 호흡을 계속한다.
5.  단전에 달걀·구슬 같은 덩어리를 만들려 하지 않는다. 이규행은 기가
    뭉치고 굳는 것은 잘못이며 반복해서 뭉친다고 생각하면 의식의 효과로
    그렇게 될 뿐이라 한다. 봉우도 “거기에 힘을 쓰니까 모이는 것”이라
    한다.
6.  수련 직후 땀을 냉수로 씻지 않는다(이규행).
7.  과로·과음·흡연·과도한 성생활은 모은 힘을 새게 한다(현암, 단학요결).
8.  **혼자서 센 호흡·지식을 연습하지 않는다.** 단학요결과 현암 모두
    책만으로는 부족하고 지도자의 점검이 필요하다고 말한다.

**건강 상태별**

- 고혈압: 날숨을 조금 길게 하고 날숨에만 뜻을 둔다(생활기공). 아랫배에
  의수하면 혈압이 내려가고 코끝에 의수하면 오른다는 서술이 있다(의수).
- 병약자: 덮어놓고 시작하지 말고 몸에 맞는 방법을 지도 아래(이규행).
