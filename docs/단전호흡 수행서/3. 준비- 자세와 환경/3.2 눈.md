# 3.2 눈

자료마다 다르다(11장). 공통되는 것은 **뚫어지게 보지 않는다**는 점이다.

- 반개: 눈꺼풀을 발처럼 드리워 코끝이 보일 정도로 내리뜬다(용호비결,
  단학요결). 눈으로 코끝을 보라는 뜻이 아니라 눈을 내리뜨라는
  뜻이다(용호비결 주해). 이규행은 “시이불시(보되 보지 않음)”가 핵심이라
  한다.
- 감은 눈: 눈꺼풀에 무게를 싣지 않고 살짝, 얼굴에 미소를 띠고(이규행).
  상이 많이 보이면 반개로(현암).
- 눈을 감으면 잡념과 헛것이 많아진다는 입장(단학요결)과, 눈을 감아야
  외부 빛이 차단된다는 입장(이규행)이 있다.
