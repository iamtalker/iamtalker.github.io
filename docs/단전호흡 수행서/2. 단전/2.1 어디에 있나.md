# 2.1 어디에 있나

자료마다 위치가 다르다. 이규행은 이유를 넷으로 든다: 해부학으로 규명되지
않았고, 사람마다 다르고, 한 치(寸)의 길이가 손가락 마디로 정해져
사람마다 다르고, 사이비 지도자가 많다.

| 자료 | 위치 |
|----|----|
| 포박자(의수·선도내공술 인용) | 배꼽 아래 2치 4푼 |
| 용호비결 | 배꼽 아래 1치 3푼. 해석본은 “배꼽 아래 5~6cm에서 안쪽으로 70% 들어간 곳”으로 풀이 |
| 봉우(민족비전) | 가운데 세 손가락을 배꼽 아래에 포갠 자리 |
| 이규행 | 배꼽 아래 3치(관원). 두 손바닥으로 역삼각형을 만들어 배꼽 밑에 대고 몸을 굽혔을 때 생기는 주름의 조금 안쪽 |
| 현암 | **전칠후삼**: 양 신장 아래·방광 위, 배꼽에서 안쪽으로 7할·선골에서 3할. 기해·석문·관원은 표피의 혈일 뿐 단전이 아니라고 함 |
| 석문호흡·이시진 | 석문혈(배꼽 아래 2치) |
| 성명규지 | 배꼽 아래 3치 |
| 정단전(성명지리론 계열) | 배꼽 |
| 선도내공술 | “정확한 위치를 따질 이유는 없고, 수련에는 배꼽 아래라는 것으로 족하다” |

**공통점 세 가지**

- 배꼽 아래, 몸 안쪽 깊은 곳이다. 표면의 한 점이 아니라 속에 있다.
- 면적이 아니라 **점**으로 잡는다. “달걀만 한 크기”라 해도 그 안에서 한
  점에 뜻을 둔다(이규행).
- 처음에는 정확한 한 점을 찾으려 애쓰지 않아도 된다. 용호비결 주해는
  “처음에는 배 표면에 중심을 두어도 무방하다”고 하고, 선도내공술도 “배꼽
  아래”로 족하다고 한다.

세 단전은 하단전(아랫배, 정)·중단전(가슴 가운데 단중, 기)·상단전(미간
안쪽, 신)이다. 입문은 **하단전**만 쓴다. 여성은 위치가 다르다는 서술이
있다(이규행, 천선정리, 여단신공): 열이 가슴 쪽에서 먼저 느껴지고 그
자리(단중 안쪽)를 중심으로 본다. **(제안)** 여성은 이 점을 지도자와
확인하는 것이 안전하다.
