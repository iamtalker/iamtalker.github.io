# 단전호흡 수행서

*위키에 모아 둔 단전호흡·조식 자료를 넓게 읽고, 공통되는 것과 갈리는 것을 나눠 정리한 입문서. 처음 시작하는 사람이 순서대로 따라 할 수 있게 썼다.*

## 0. 읽기 전에

- **근거**: 위키에 있는 타인의 글과 고전. 현대 수련서([단전호흡](<단전호흡.md>)(이규행), [민족비전 정신수련법](<민족비전 정신수련법.md>)(봉우 권태훈의 호흡법·수련문답), [단학요결](<단학요결.md>), [단전호흡 소주천 대주천 요점정리](<단전호흡 소주천 대주천 요점정리.md>)(현암), [금단의 길](<금단의 길.md>), [한단회](<한단회.md>), [포기천](<포기천.md>)), 중국 기공서 번역([선도내공술](<선도내공술.md>), [생활기공](<생활기공.md>), [의수](<의수.md>), [내호흡](<내호흡.md>), [조식](<조식.md>), [잠호흡](<잠호흡.md>)), 고전([용호비결](<용호비결.md>), [수진비록](<수진비록.md>), [삼법회통](<삼법회통.md>), [태을금화종지](<태을금화종지.md>), [성명규지](<성명규지.md>), [금선증론](<금선증론.md>), [천선정리](<천선정리.md>), [혜명경](<혜명경.md>), [활인심방](<활인심방.md>) 등), 비교용으로 [월창거사](<월창거사.md>)·[안반수의로 얻는 깨달음의 세계](<안반수의로 얻는 깨달음의 세계.md>)·[고엔카](<고엔카.md>)·[하타요가프라디피카](<하타요가프라디피카.md>)를 읽었다. 직접 쓴 글(일지·메모)은 근거에서 뺐다.
- **읽은 범위**: 호흡·단전을 다루는 문서 약 60개. 분량이 큰 책(선도내공술·생활기공·민족비전·방도어록·금단의 길)과 고전(태을금화종지·금선증론·성명규지 등)은 호흡·단전이 나오는 대목을 골라 읽었고, 짧은 문서와 단전호흡 소개서는 전부 읽었다. [단전호흡](<단전호흡.md>)과 [단전 호흡과 정신문화](<단전 호흡과 정신문화.md>)는 같은 책의 사본이다. 읽지 못한 것: 태을금화종지의 다른 버전(67만 자), [단수련법](<단수련법.md>), [북창내단사상연구](<북창내단사상연구.md>)의 본문(요약 대목만 확인). 이전에 쓴 [claude 편집자:단학 수행서](<claude 편집자：단학 수행서.md>)는 그대로 두었다.
- **범위**: 자세·호흡·마음 쓰기, 숨의 길이를 늘리는 법, 몸의 신호, 소주천 입구까지. 대약·도태·출신 같은 뒤 단계는 고전의 서술이 있을 뿐 이 자료만으로 확인할 수 없어 다루지 않는다.
- **표기**: 자료마다 말이 다른 곳은 "자료마다 다르다"고 적고 11장에 모았다. "(제안)"은 자료에 없는 이 글의 정리다.
- **건강**: 의학 조언이 아니다. 지병이 있거나 수련 중 이상 반응이 심하면 멈추고 진료를 받는다. (7장)

## 1. 단전호흡이란

### 1.1 한 줄 정리

**아랫배(단전)에 뜻을 두고, 숨을 가늘고 길고 고르게 해서 기를 단전에 모으는 수련.** 숨을 다스리는 일(조식)이 중심이고, 몸(자세)과 마음(뜻을 두는 법)이 함께 간다.

### 1.2 두 가지 뜻

자료들이 "단전호흡"이라는 말을 두 가지로 쓴다. 섞어 읽으면 혼란스럽다.

| 뜻 | 내용 | 쓰는 자료 |
| --- | --- | --- |
| 넓은 뜻 | 아랫배에 의식을 두고 하는 호흡 수련 전체. 초심자에게 권하는 아랫배 호흡이 여기 든다. 건강에는 이것으로 충분하다고 본다(이규행). | 이규행, 선도내공술(복식호흡으로 횡격막을 움직이는 단전선 조식법) |
| 좁은 뜻 | 수련이 깊어져 **단전기혈이 스스로 숨 쉬는 것**(기식·내호흡·태식). 코의 숨소리는 거의 사라지고 단전 부위가 오므라들었다 펴지는 움직임이 있다. 이규행은 이를 폐호흡이 배제된 "진단전호흡"이라 부른다. | 현암, 이규행, 선도내공술의 태식 |

복식호흡과의 관계도 갈린다. 현암은 "복식호흡 차원의 호흡을 하면서 단전호흡이라 하는 경우가 많다"고 말하고, 이규행은 복식호흡이 배 전체를 쓰는 데 비해 토납법은 **아랫배에 국한**된다고 구분한다. 이 글은 넓은 뜻으로 출발해서 좁은 뜻으로 가는 길을 쓴다.

### 1.3 이름이 여럿이다

토납(吐納), 조식(調息), 복기·누기·유기·적기·축기, 폐기(閉氣), 태식(胎息), 단전호흡이 모두 비슷한 영역을 가리킨다. 정리하면 이렇다.

| 말 | 대체로 쓰는 뜻 |
| --- | --- |
| 토납 | 탁한 기를 뱉고 맑은 기를 마심. 깊은 숨. 입문 호흡으로 보는 자료가 있다(이규행). |
| 조식 | 숨을 고름. 들숨과 날숨의 길이를 같게 하고 가늘고 길게 만든다. 한국 선도 자료의 중심. |
| 폐기·복기·유기·축기 | 기를 단전에 머물게 함. **숨을 멈추는 것이 아니다**(5장). |
| 태식 | 태아의 호흡. 숨이 코가 아니라 단전(배꼽)에서 이루어지는 듯한 상태. 수련의 결과로 본다. |

## 2. 단전

### 2.1 어디에 있나

자료마다 위치가 다르다. 이규행은 이유를 넷으로 든다: 해부학으로 규명되지 않았고, 사람마다 다르고, 한 치(寸)의 길이가 손가락 마디로 정해져 사람마다 다르고, 사이비 지도자가 많다.

| 자료 | 위치 |
| --- | --- |
| 포박자(의수·선도내공술 인용) | 배꼽 아래 2치 4푼 |
| 용호비결 | 배꼽 아래 1치 3푼. 해석본은 "배꼽 아래 5\~6cm에서 안쪽으로 70% 들어간 곳"으로 풀이 |
| 봉우(민족비전) | 가운데 세 손가락을 배꼽 아래에 포갠 자리 |
| 이규행 | 배꼽 아래 3치(관원). 두 손바닥으로 역삼각형을 만들어 배꼽 밑에 대고 몸을 굽혔을 때 생기는 주름의 조금 안쪽 |
| 현암 | **전칠후삼**: 양 신장 아래·방광 위, 배꼽에서 안쪽으로 7할·선골에서 3할. 기해·석문·관원은 표피의 혈일 뿐 단전이 아니라고 함 |
| 석문호흡·이시진 | 석문혈(배꼽 아래 2치) |
| 성명규지 | 배꼽 아래 3치 |
| 정단전(성명지리론 계열) | 배꼽 |
| 선도내공술 | "정확한 위치를 따질 이유는 없고, 수련에는 배꼽 아래라는 것으로 족하다" |

**공통점 세 가지**

- 배꼽 아래, 몸 안쪽 깊은 곳이다. 표면의 한 점이 아니라 속에 있다.
- 면적이 아니라 **점**으로 잡는다. "달걀만 한 크기"라 해도 그 안에서 한 점에 뜻을 둔다(이규행).
- 처음에는 정확한 한 점을 찾으려 애쓰지 않아도 된다. 용호비결 주해는 "처음에는 배 표면에 중심을 두어도 무방하다"고 하고, 선도내공술도 "배꼽 아래"로 족하다고 한다.

세 단전은 하단전(아랫배, 정)·중단전(가슴 가운데 단중, 기)·상단전(미간 안쪽, 신)이다. 입문은 **하단전**만 쓴다. 여성은 위치가 다르다는 서술이 있다(이규행, 천선정리, 여단신공): 열이 가슴 쪽에서 먼저 느껴지고 그 자리(단중 안쪽)를 중심으로 본다. **(제안)** 여성은 이 점을 지도자와 확인하는 것이 안전하다.

### 2.2 단전에 뜻을 두는 법

이 부분이 자료마다 가장 크게 갈린다. 먼저 공통점이다.

- **힘을 주지 않는다.** 단전은 "의식을 싣는 곳"이지 힘을 주거나 무게를 싣는 곳이 아니다. 힘을 주면 가슴과 어깨에 힘이 들어가 부작용이 난다(이규행).
- **뜻을 둔다.** 생각하거나 상상하는 것이 아니라 뜻(의지)을 은은히 둔다(의수, 용호비결의 의수단전).
- 단전이 너무 뜨거워지면 의수 시간이 길었거나 의식이 과한 것이니 가라앉힌다(선도내공술의 퇴화공).

갈리는 점은 이렇다. (11장에 표로 모았다.)

- 아랫배에 뜻을 두는 것을 기본으로 삼는 쪽: 용호비결, 현암, 이규행, 한단회, 중국 기공 교재.
- 처음 수련자에게는 아랫배에 집중하라는 것이 어렵다고 보는 쪽: 선도내공술은 "들이마시면서 집중하려 하면 호흡이 1\~2초 끊기고, 배를 외부의 힘으로 내밀고 넣는 나쁜 습관이 든다"고 하며, 눈을 가볍게 감고 **가는 빛이 코끝에 와 닿는다고 생각하며** 코로 조용히 숨 쉬는 방법을 권한다.
- 한 곳을 지키지 않는 쪽: 방도어록이 소개하는 정좌법은 "규(竅)를 지키지 않는다. 하단전을 지키면 쉽게 효과를 보지만 잘못하면 병이 나고, 머리 등 다른 규는 폐해가 더 심하다"고 한다. 응신입기혈은 의수단전을 "방문(곁길)"이라 하고, 태을금화종지는 몸 안을 살피며 숨 쉬는 것은 명(命)의 맥이 되지 않는다고 한다.
- 중간: 방도어록의 문답은 "뜻을 호흡에 두지 말라, 그러면 조절하지 않아도 스스로 조절된다"고 하고, 단학요결은 "누가 배에 신경 쓰라 했는가, 호흡에만 신경 쓰면 자연히 배가 나오고 들어간다"고 한다.

**(제안)** 처음에는 숨이 코로 드나드는 흐름에 주의를 두고, 숨이 고르게 되면 단전에 뜻을 **은은히** 얹는다. 상단전(미간)이나 머리에 뜻을 올리지 않는다. 그 이유는 7장에 있다.

## 3. 준비: 자세와 환경

세 가지를 고르는 것(조신·조식·조심)이 기본이고, 선도내공술은 셋이 "불가분이며 서로 촉진한다"고 한다. 이 장은 몸이다.

### 3.1 자세

| 부위 | 요령 | 근거·참고 |
| --- | --- | --- |
| 앉는 법 | 결가부좌·반가부좌·평좌 중 **오래 앉아 편한 것**. 방석으로 엉덩이를 약간 높여 골반을 편하게. 다리는 번갈아 바꿔 골반이 한쪽으로 쏠리지 않게. | 용호비결 주해, 현암, 단학요결, 방도어록 |
| 척추 | 억지로 곧추세우지 않고 **자연스러운 곡선**을 유지. 용호비결의 "수레바퀴처럼 둥글게"가 이 뜻. | 용호비결 주해 |
| 턱 | 살짝 당긴다. 목 뒤(대추)가 꺾이면 기가 막힌다는 설명. | 현암, 수승화강 |
| 어깨·가슴 | 어깨를 한 번 뒤로 젖혔다가 힘을 빼고 내린다. 명치에 힘 빼기. | 현암 |
| 혀 | 혀끝을 윗잇몸·입천장에 가볍게 댄다(임·독맥을 잇는다고 봄). 침이 고이면 삼킨다. | 현암, 이규행, 단학요결 |
| 손 | 아랫배 앞에 가볍게 모으거나 무릎 위. 남녀 손 위치를 반대로 하는 전통이 있다(법계정인). | 이규행, 현암 |
| 몸 전체 | 어디에도 힘이 들어가지 않게 이완. 가볍게 미소. | 현암, 함흉발배 |

**좌법을 점검하는 법(이규행)**: 앉은 사람의 앞가슴을 뒤로 가볍게 밀었을 때 쉽게 넘어가면 좌법이 틀린 것이다. 중심이 하단전에 잡혀야 한다.

### 3.2 눈

자료마다 다르다(11장). 공통되는 것은 **뚫어지게 보지 않는다**는 점이다.

- 반개: 눈꺼풀을 발처럼 드리워 코끝이 보일 정도로 내리뜬다(용호비결, 단학요결). 눈으로 코끝을 보라는 뜻이 아니라 눈을 내리뜨라는 뜻이다(용호비결 주해). 이규행은 "시이불시(보되 보지 않음)"가 핵심이라 한다.
- 감은 눈: 눈꺼풀에 무게를 싣지 않고 살짝, 얼굴에 미소를 띠고(이규행). 상이 많이 보이면 반개로(현암).
- 눈을 감으면 잡념과 헛것이 많아진다는 입장(단학요결)과, 눈을 감아야 외부 빛이 차단된다는 입장(이규행)이 있다.

### 3.3 때와 곳

- 매일 **같은 시간**에. 새벽이 좋다는 서술이 있다(단학요결은 인시 3\~5시, [조식](<조식.md>) 문서는 해 뜰 무렵, 삼법회통은 새벽빛이 훤할 때). 현암은 몸과 마음이 가장 고요한 때를 권한다.
- 통풍이 되고 공기가 맑은 곳. 담배 연기와 먼지는 피한다. 식후 바로는 피한다(선도내공술의 11주의).
- 길게 하는 것보다 **끊기지 않는 것**이 낫다는 말이 여러 곳에 있다.

## 4. 호흡

### 4.1 모든 자료의 공통 원칙

1. **코로** 한다. 입은 다문다(봉우: "색태, 입을 닫고 코로만"). 코 질환이 있으면 입을 쓸 수 있다.
2. **소리가 나지 않게.** 봉우는 코 밑에 밀가루나 가는 털을 붙여도 움직이지 않을 만큼이라고 한다.
3. **힘을 쓰지 않는다.** 억지 호흡이 부작용의 가장 흔한 원인이다. 선도내공술은 "호흡에 힘을 넣지 말라", 현암은 "강제로 하면 장애가 온다"고 한다.
4. **들숨과 날숨의 길이를 같게.** 봉우, 단학요결, 삼법회통, 용호비결 해석본이 같은 말을 한다.
5. **가늘고(細) 길고(長) 고르고(均) 깊게(深), 끊어지지 않게(綿).** 단학요결의 팔자결(유·세·완·균·정·면·심·장)이 이를 모은 것이다.
6. **여유를 남긴다(常有一寸餘氣).** 폐활량의 끝까지 들이쉬거나 내쉬지 않는다. 더 쉴 수 있는 여유를 두고 바꾼다(단학요결, 봉우).
7. **서두르지 않는다.** 숨 길이는 시간이 만든다.

### 4.2 좋은 숨과 나쁜 숨: 풍·천·기·식

이규행과 월창거사(천태지관 계열)가 같은 네 가지로 호흡의 상태를 나눈다.

| 상 | 모습 | 결과 |
| --- | --- | --- |
| 풍(風) | 숨소리가 난다 | 기가 흩어진다 |
| 천(喘) | 헐떡이듯 막히고 끊긴다 | 기가 막히고 맺힌다 |
| 기(氣) | 소리는 없으나 거칠고 가늘지 않다 | 피로하다 |
| 식(息) | **소리 없고, 맺히지 않고, 거칠지 않고, 솜털처럼 가늘고, 있는 듯 없는 듯** | 좋은 숨. 조식이 되고 선정에 든다 |

목표는 식상이다. 나머지는 피한다.

### 4.3 숨의 길이를 늘리는 단계

사다리처럼 한 단계씩 오른다. 아래 단계가 몸에 붙지 않았는데 위로 가면 탈이 난다.

| 단계 | 하는 일 | 확인 |
| --- | --- | --- |
| 1. 묵좌식상 | 평소 호흡 그대로 고요히 앉아 잡념을 쉬는 연습. 봉우는 약 1주일, 단학요결은 약 20일을 말한다. | 앉아 있는 것이 불편하지 않다 |
| 2. 자연호흡·숨결 고르기 | 평소 호흡을 바꾸지 말고 **일정하게** 만든다. 짧으면 짧은 대로, 길면 긴 대로 속도와 양을 한결같이(생활기공). 무리하게 늘려 빡빡하게 몰아쉬지 않는다(봉우). | 숨이 할딱임·한숨·고르지 않음이 줄어든다 |
| 3. 복식(아랫배 호흡) | 숨이 아랫배까지 내려가는 호흡. 배의 움직임은 4.4. | 아랫배가 부드럽게 움직인다 |
| 4. 조식 | 들숨과 날숨을 같은 길이로 맞춰 점차 늘린다. 시계로 재거나 속으로 센다(봉우). 예: 들숨 2초·날숨 2초에서 시작해 3초·3초로. | 같은 길이로 끊김 없이 이어진다 |
| 5. 유기(축기) | 조식이 되면 **일부러 한 호흡을 줄여서** 뜻을 단전에 둔다. 봉우의 예: 20초 조식(10초+10초)을 하는 사람이 7초+7초로. 여유 있는 호흡이 되어 오히려 길이가 빨리 는다. | 아랫배가 따뜻하고 숨이 편안하다 |
| 6. 폐기·태식 | 숨 흐름이 단전 쪽으로 가라앉고 코의 숨이 거의 느껴지지 않음. **시도해서 되는 것이 아니라 5단계의 결과.** | 5장 참조 |

**길이 목표**는 자료마다 다르다. 개인차가 크니 참고만 한다. 한 호흡은 들숨과 날숨을 합한 시간이다.

| 자료 | 서술 |
| --- | --- |
| 보통 사람(이규행·선도내공술) | 한 호흡 3\~4초, 분당 15\~18회 |
| 생활기공 | 들숨 4\~5초·날숨 4\~5초, 분당 6\~8회를 목표. 연습하면 4회까지 |
| 봉우(민족비전) | 묵좌 1주 → 자연호흡 하루 2시간 이상 총 30일 → 조식(시계로 재며 연장). 호흡법 서문은 불휴불식 2개월쯤이면 한 호흡 20초, 수련문답은 10초에서 20초가 한 달, 20초에서 30·40초는 반 년이라 한다. 40초를 넘으면 추기 단계 |
| 단학요결 | 20일 무타념 호흡 → 10일 가늘고 고르게 → 2개월 연장 → 3개월쯤 20초 → 폐기를 시작해 6개월 35초 → 7개월 40초 → 1년 반\~2년에 정좌 1분·평상시 30초 |
| 현암 | 시간표 대신 40분 수련을 기본(초보 20분부터) |

**단학요결의 점검 기준**: 수련 중에 1분이라 자처해도 평상시 30초가 안 되면 조식이 끊기는지 의심하라는 것이다.

**처음 시작할 때 (단학요결 문답 정리)**

- 길게와 고르게 중 **고르게가 먼저.** 한 호흡이 5\~6초여도 고르면 입정할 수 있다.
- 들숨과 날숨 중 한쪽이 짧으면 **짧은 쪽에 맞춘다.** 서서히 둘을 늘린다.
- 이마가 먹먹하고 머리가 조이는 것은 초심자에게 흔하다. 두통·목덜미 통증이면 숨을 끝까지 쉬어 여유를 남기지 않은 것이다.

### 4.4 배는 어떻게 움직이나

자료가 갈리는 대표적인 곳이다. 먼저 말을 정한다.

- **순호흡**: 들숨에 아랫배가 나오고 날숨에 들어간다. 자연스러운 복식호흡.
- **역호흡**: 들숨에 아랫배가 들어가고 날숨에 나온다.
- 책에 따라 이 이름이 반대로 쓰이기도 한다(선도내공술의 "정호흡=역호흡" 표현). 이름보다 **배의 움직임**으로 읽는다.

| 방식 | 쓰는 자료 | 평가 |
| --- | --- | --- |
| 순호흡 | 이규행(토납법), 현암, 단학요결, 봉우, 생활기공, 선도내공술의 기본 복식, 방도어록(왕찬빈의 자연호흡) | 대부분 기본으로 삼는다 |
| 역호흡 | [내호흡](<내호흡.md>)·[조식](<조식.md>)·[잠호흡](<잠호흡.md>)(중국 기공 교재), 이규행의 역토납(열감이 안 생길 때 보조), 포기천(보조), 선도내공술(태극권 호흡 설명) | 중국 기공 교재는 정공 호흡 방식으로 소개한다. 포기천은 일반 단전호흡의 1/5만, 길게 하지 말라고 한다. 선도내공술은 역호흡의 운동량이 더 커서 순호흡과 번갈아 연습하라고 한다 |
| 봉우의 평가 | 역호흡은 호흡이 빨리 길어지나(2\~3개월 걸릴 것이 한 달 반) **정신이 밝아지지 않는다.** 힘을 쓸 때에나 필요하다. 정신을 연구하거나 능력을 계발하려면 순호흡만 하라 |  |

배를 움직이는 요령에 관한 말은 일치한다.

- **배는 호흡의 결과다. 일부러 내밀거나 넣지 않는다.** 생활기공: 날숨에 아랫배에 약간 힘을 줘 들이밀고, 힘을 빼면 들어갔던 배가 저절로 돌아오며 들숨이 된다. 먼저 내밀었다 돌아가게 하는 것이 아니라 **먼저 들이밀었다 돌아가게** 하라고 한다.
- 현암: 들숨 때 배가 나오게 하려고 힘주지 말 것. 저절로 들어오는 만큼만 들이쉰다.
- 단학요결: "지금 배 불리는 연습을 하고 있는가, 호흡에만 신경 쓰면 자연히 들이쉴 때 나오고 내쉴 때 들어간다." 하복부가 나온 것만 자랑하는 수련을 비판한다.

### 4.5 입으로 뱉는 호흡(토호흡)

탁한 숨을 먼저 비우는 방식이 여러 곳에 있다. 이 방식을 입문의 첫 단계로 보는 자료와 보조로 보는 자료가 있다.

- 이규행: **토납법이 첫 호흡법**이고 조식은 그다음이다. 뱉는 숨부터 시작하고(호흡의 호가 흡 앞에 있다), 탁기를 다 뱉은 뒤 천천히 들이쉰다. 뱉을 때 혀끝은 아랫니 뒤, 들이쉴 때는 입천장. 입으로 뱉든 코로 뱉든 선택이며 몸이 약하면 입이 먼저. 토납을 6년 한 뒤에야 조식에 든 사례를 든다.
- 현암: 수련 앞에 **토호흡**(아·에·이·오·우 중 한 소리를 길게 내쉬며 단전에서 울려 나오게, 5\~6회)과 흡호흡을 한다.
- 성명규지: 입 안에서 혀를 여러 번 휘두른 뒤 가늘게 소리 없이 탁기를 토하고 코로 알듯 말듯 들이마심을 14\~15번 하고, 고인 침을 삼킨다.
- 활인심방: 동쪽을 보고 '휘' 소리로 묵은 공기를 두세 모금 불어낸 뒤 코로 맑은 기를 들이마신다. 오장에 따라 소리를 달리하는 육자결도 있다.
- 봉우와 단학요결은 토납 단계를 따로 두지 않고 묵좌 → 자연호흡 → 조식으로 간다.

**(제안)** 수련 앞에 탁한 숨을 입으로 소리 없이 길게 3\~6번 내쉬는 정도는 어느 자료와도 어긋나지 않는다. 그 뒤에는 코로만 한다.

## 5. 숨을 멈추는가: 폐기·지식·폐식

용호비결의 "폐기"가 가장 많이 오해되는 말이다. 자료를 정리하면 이렇다.

| 자료 | 폐기 | 지식 | 폐식 |
| --- | --- | --- | --- |
| 용호비결 주해 | 숨을 멈추지 않고 **기운이 단전에 머물게** 함. 예부터 지식으로 오인해 숨을 멈추다 부작용 |  |  |
| 이규행 | 호흡의 결과(경지). 입정 후 단전이 기로 차고 숨 쉬는 것도 잊는 상태 | 숨 멈춤이 아니라 가늘게 이어지는 호흡 속에서 **정신이 머무는 것**. 억지로 참으면 힘이 들어가고 상기·진동·환각(산소 부족) | 방법이 아니라 결과 |
| 현암 | 봉고(수련 끝에 기를 단전에 입실시킴)와 같은 뜻 | 들숨 후 기도를 연 채 호흡이 나가지도 들어가지도 않는 머무름. 막힌 혈이 뚫릴 때까지만 | 기도를 닫고 아랫배에 힘을 주는 호흡. **수련 중 몸을 상하는 경우 대부분이 이것** |
| 봉우 | 단전에 기운이 머물게 함(유기) | 백두산족 고유의 호흡이 아니다. 정신과 무관하고 격파 같은 힘쓰는 데만 소용 | 단학에서 제일 꺼리는 것. 기합술·씨름·차력의 호흡 |
| 단학요결 | 복기·누기·유기·축기. 내쉴 때 공(空)만 내쉬고 기는 단전에 둔다고 서술 | 사념을 멈춤이라는 설이 유력 | **단학에는 폐식이 없다.** 숨을 정지하면 흉부 압력이 올라 정맥 순환이 막히고 울혈·정맥류·뇌압 상승 |
| 방도어록 |  |  | 강제 폐식은 병, **자연 폐식**(미세해진 숨이 저절로 멎음)은 폐단 없음 |
| 선도내공술 |  |  | 호흡 정지를 무리하게 하지 말 것(주의 11조) |
| 혜명경·천선정리 등 고전 | 숨을 멈추거나 닫는 서술이 일부 있음 |  |  |
| 하타요가프라디피카 |  | **쿰바카(지식)가 핵심 기법**, 횟수를 날마다 늘림 |  |

**정리**

- 입문 수련에서 **의식적으로 숨을 멈추지 않는다**는 데 현대 지침서가 거의 일치한다.
- 멈춘 듯한 상태는 숨이 가늘어진 결과로 저절로 온다. "저절로 머무는 것"과 "참는 것"은 다르다.
- 숨을 멈추는 서술은 상급 고전(혜명경 등)과 요가, 무술·차력 계열에 있다. 이규행과 봉우는 멈춤 호흡을 조식과 구분한다.

## 6. 마음 쓰기

### 6.1 마음과 숨을 붙인다

공통되는 것은 **마음을 숨에 붙여 흩어지지 않게 하는 것**이다.

- 태을금화종지의 심식상의(心息相依): 마음과 숨이 서로 의지한다. "숨소리를 듣되 소리 없는 소리를 듣는다."
- 봉우·단학요결의 **무타념 무타상**: 무념무상이 아니라 "다른 생각, 다른 상(想)을 하지 말고 호흡하는 생각 그대로". 숨이 드나드는지 모를 정도로 멍한 것은 조식이 아니다.
- 수식(數息): 월창거사는 **들숨이나 날숨 한쪽만** 1에서 10까지 센다고 한다(둘 다 세면 숨 막는 병). 성명규지는 마음이 숨에 붙어 세지 않아도 맞을 때 헤아림을 놓고 저절로 이루어지는 숨에 맡긴다고 한다. 생활기공은 복식호흡이 궤도에 오르면 숨이 아니라 하복부의 움직임에 주의를 두고, 센다면 배가 움직이는 횟수를 센다고 한다.
- 고엔카(위빠사나)는 반대로 세거나 말을 붙이지 말고 있는 그대로의 호흡을 알아차리라고 한다(비교는 10장).

### 6.2 잡념

- 잡념을 없애려는 생각 자체가 잡념이다. 무관심이 방법이다. "너는 너대로 놀다 가라" 하고 들어오는 숨에 기가 쌓이고 나가는 숨이 노폐물을 싣고 나간다는 데만 의식을 둔다(단학요결).
- 현암도 상념은 지우려 할수록 더 일어난다고 하며, 단전을 관(觀)하고 호흡에 열중하라고 한다. 눈동자가 움직이면 이미 딴 생각이 든 것이다.
- 잡념이 심하면 발바닥을 문지르거나 눈을 덮거나 잠깐 걷고 다시 앉는다(방도어록).

### 6.3 졸음과 멍함

- 졸리면 억지로 하지 말고 푹 잔 뒤 한다. 수련 중 잠드는 습관이 들면 고치기 어렵다(현암).
- 봉우: 호흡에 재미를 붙이면 잠이 안 오고, 숨이 짧으면 피로해서 졸린다. 졸릴 때 눕지 말고 몸을 푼 뒤 다시 한다.
- 졸림을 정(定)으로 착각하지 않는다. 생각이 아주 없는 멍함은 무기공(無記空)이라 하여 금한다(현암).

## 7. 몸이 보내는 신호와 주의

### 7.1 괜찮은 신호

- 아랫배에서 배가 꾸르륵거리고 우레 같은 소리, 가슴이 번거로이 차거나 뱃속이 아프다가 무언가 내려가는 느낌. 용호비결·수진비록·봉우가 "제대로 되어 가는 징조"라 한다.
- 아랫배·손발이 따뜻해짐. 침이 고임(삼킨다). 트림·방귀·설사, 몸살, 일시적 마른기침 같은 명현(현암).
- 초보자가 서늘함을 느끼는 것은 양기가 음기를 밀어내는 과정이라는 설명(현암).
- 대부분 저절로 지나가므로 걱정하지 않는다.

### 7.2 멈추고 점검할 신호

| 신호 | 자료의 설명 | 처방 |
| --- | --- | --- |
| 명치가 아프고 상복부가 딱딱해짐, 기가 단전에 안 내려옴 | 호흡 요령이 틀린 것(봉우) | 즉시 중지하고 믿을 만한 지도자에게 점검 |
| 두통, 목덜미·어깨 통증, 이마가 조임 | 호흡을 최대로 하여 여유를 남기지 않음(단학요결). 지식·센 호흡으로 생긴 탁기가 머리로 몰림(금단의 길) | 호흡을 줄이고 여유를 남김. 의식을 단전·발바닥으로 내림 |
| 양쪽 옆구리 통증 | 호흡에 힘을 너무 넣음(선도내공술) | 호흡량을 줄이고 가볍게, 몸을 풀고 옆구리를 문지름 |
| 단전이 너무 뜨거움 | 의수가 길었거나 의식 과중(선도내공술) | 뜻을 풀어 가라앉힘 |
| 콧구멍의 숨이 뜨거운 밥 김 같음 | 방도어록: 그대로 두면 각혈·내장 손상 | 잠시 쉼 |
| 얼굴이 붉고 머리가 뜨겁고 혈압·두근거림 (상기) | 올라가는 것 자체는 자연스러우나 **내려오지 않는 것이 문제**(주화). 센 호흡·강한 의념·욕심이 원인 | 의식을 하단전으로, 안 되면 발바닥(용천)으로. 발바닥을 문지름(이규행) |
| 정수리가 짓눌림(태산압정) | 기감을 얻으려 애쓰거나 초심자가 억지로 기를 돌릴 때(이규행) | 의식적으로 기를 내림. 두통이 심하면 중지하고 이완, 온몸을 가볍게 두드림 |
| 몸이 저절로 떨리고 뛰거나 춤을 춤 | 진동이 잠깐 오는 것은 있을 수 있으나 키우거나 빠지면 주화(수련의 부작용). 봉우: 호흡이 걸리면 진동이 되니 다시 호흡을 고름 | 이완공·몸 푸는 운동으로 바꿈 |
| 환시·환청·불안·초조·강박 (입마) | 오랜 수련자도 빠질 수 있음 | 수련을 멈춤. 정신과·한방 진료. 평소 정신 질환이 있으면 정공보다 동공을 권함 |

수련을 그만두면 대개 회복된다고 한다. 사람에게 복원력이 있어서이다(수련의 부작용).

### 7.3 하지 말아야 할 것

1. 억지로 하지 않는다. 호흡도 자세도 기를 돌리는 것도.
2. 숨을 참거나 닫지 않는다(5장).
3. **의식을 위로 올리지 않는다.** 이규행은 바른 지침 없이 상단전 수련을 하는 것은 금기라 하고, 현암은 상을 보려 상단전에 의식을 올리면 단전에 모은 기가 소모된다고 한다. 응신입기혈도 잡념이 분분한 채 조규·단전 같은 특정 규를 의수하면 두통·어지럼·주화입마가 온다고 경고한다.
4. 상(象)·소리·빛을 쫓지 않는다. 이규행은 기감에 흥분하는 것, 기의 엑스터시에 빠지는 것이 두 번의 함정이라 한다. 방도어록과 현암: 보이는 것을 들여다보지 말고 호흡을 계속한다.
5. 단전에 달걀·구슬 같은 덩어리를 만들려 하지 않는다. 이규행은 기가 뭉치고 굳는 것은 잘못이며 반복해서 뭉친다고 생각하면 의식의 효과로 그렇게 될 뿐이라 한다. 봉우도 "거기에 힘을 쓰니까 모이는 것"이라 한다.
6. 수련 직후 땀을 냉수로 씻지 않는다(이규행).
7. 과로·과음·흡연·과도한 성생활은 모은 힘을 새게 한다(현암, 단학요결).
8. **혼자서 센 호흡·지식을 연습하지 않는다.** 단학요결과 현암 모두 책만으로는 부족하고 지도자의 점검이 필요하다고 말한다.

**건강 상태별**

- 고혈압: 날숨을 조금 길게 하고 날숨에만 뜻을 둔다(생활기공). 아랫배에 의수하면 혈압이 내려가고 코끝에 의수하면 오른다는 서술이 있다(의수).
- 병약자: 덮어놓고 시작하지 말고 몸에 맞는 방법을 지도 아래(이규행).

자료에서 겹치는 부분만 골라 짠 예시다. 몸 상태에 맞게 줄인다.

### 8.1 한 번 앉을 때

| 2. 자세 | 3장의 자세. 다 이완될 때까지 기다린다. | 2분 |

| 5. 조식 | 들숨=날숨의 길이로 가늘고 부드럽게. 속으로 센다. 끝까지 쉬지 않고 **여유를 남긴다**. | 10\~20분 |

## 9. 소주천의 입구

호흡이 익으면 아랫배에 열감(불씨)이 생기고, 기가 임·독맥을 도는 소주천으로 이어진다는 것이 모든 자료의 큰 줄거리다. 이 글은 입구만 쓴다.

- **기가 차면 저절로 돈다.** 이규행·단학요결·현암이 같은 말을 한다. 처음부터 기를 끌어올리려 하지 않는다. 의식으로 임독을 돌리는 것(가주천·공차)은 본래 주천과 다르다(단학요결, 현암).
- 소주천만 돌리고 단전에 뿌리가 없으면 불씨가 생기지 않는다. 한 수련자는 1년 넘게 주천만 하다가 불씨를 못 만들었다고 적었다(나의 소주천). 금단의 길도 일차 주천 뒤에는 **단전에 집중해 소약을 키우라**고 한다.
- 관문(미려·협척·옥침) 통과법: 이규행은 **가벼운 의식과 약한 호흡(문식)으로 접근하다 진동이 오면 의식을 단전으로 옮겨 강한 의식과 호흡**을 쓰고, 안 되면 풀고 반복한다고 한다. 현암은 막힌 곳에서 의식을 모아 호흡을 아주 부드럽게 하는 **온양**을 쓰고, 그래도 안 되면 지식(기도를 연 머무름)을 쓰되 폐식은 하지 않는다고 한다.
- 문화(文火, 부드러운 호흡)와 무화(武火, 강한 호흡): 선도내공술은 미약한 의념과 유화한 호흡을 문화, 강렬한 의념과 급중한 호흡을 무화라 하고, **주화는 강한 의념과 급한 호흡을 쓸 때 생기는 편차의 하나**라 한다. 수련 단계가 깊어질수록 문식 위주로 간다(금선기공).
- 이후의 소약·대약·도태는 이 글의 범위 밖이다.

## 10. 다른 전통과의 비교

호흡 수련은 선도에만 있지 않다. 위키에 있는 불교·요가 자료와 비교하면 단전호흡의 특징이 보인다.

| 전통 | 호흡을 어떻게 다루나 | 단전호흡과의 차이 |
| --- | --- | --- |
| 선도(한국 조식 계열) | 호흡을 다스려 기를 단전에 모음. 조식·유기. 의식적 멈춤을 경계 |  |
| 불교 수식관(월창거사·천태) | 수(숫자 세기)→수(따라가기)→관→환. 날숨이나 들숨 한쪽만 센다. 마음이 어지러운 사람에게 먼저 | 목적이 단전의 기가 아니라 마음 안정과 관찰. 단전 개념 없음 |
| 안반수의 | 수식·상수·지·관·환·정. 호흡과 마음이 하나가 되게 | 안반수의 해설도 "단전호흡은 복압을 높여 건강을 회복시키나 일상에서 가장 쉬운 것은 안반수의"라 함 |
| 위빠사나(고엔카) | 호흡을 조절하지 않고 **있는 그대로 알아차림**. 세거나 말을 붙이지 않음. 요가식 호흡 조절과 섞지 말라 | 조절하지 않는다는 점이 다름 |
| 하타요가 | 들숨·날숨·**지식(쿰바카)**. 지식이 핵심 기법이고 횟수를 늘림. 쿤달리니 | 숨 멈춤을 쓰는 점이 다름. 이규행은 선도를 기의 하강, 요가를 상승 체계로 봄(저자 견해) |

공통점: 모든 전통이 **호흡이 고요해지면 마음이 고요해진다**고 본다. 단학요결은 "수련법이 달라도 삼매에 들면 결국 조식이 된다"고 쓴다. 한편 방도어록에 인용된 한 서술은 기(氣)를 성명의 근본으로 보는 것을 외도라 한다.

| 항목 | 갈리는 의견 |

| 정자세 | 궤좌(무릎 꿇기, 이규행) / 가부좌·평좌 중 편한 것(대다수) |
| 수련 이름 | 단학 vs 단전호흡: 단학요결 저자는 조식·폐기 중심을 "단학", 지식·폐식·의식으로 기를 돌리는 쪽을 "단전호흡"이라 구분. 위키의 다른 문서는 둘을 같은 말로 씀 |

이 차이는 **출발점(어느 유파·시대의 서술인가)** 에서 온다. 입문자는 대체로 "힘 빼기, 코로, 소리 없이, 고르게, 여유 남기기, 멈추지 않기"에서 만난다.

## 12. 용어 사전

| 용어 | 뜻 |
| --- | --- |
| 조신·조식·조심 | 몸·숨·마음을 고름 |
| 단전·기해·관원·석문 | 기를 모으는 곳과 그 부근 혈 이름 |
| 의수단전 | 뜻을 단전에 둠 |
| 문식·무식 / 문화·무화 | 부드러운 호흡·강한 호흡 |
| 순호흡·역호흡 | 들숨에 배가 나옴 / 들어감 |
| 풍·천·기·식 | 호흡의 네 상태. 식이 좋은 숨 |
| 팔자결 | 유·세·완·균·정·면·심·장 |
| 상유일촌여기 | 한 치의 여유를 남기는 호흡 |
| 폐기·복기·유기 | 기운을 단전에 머물게 함 |
| 지식 | 숨이 머무름(자료에 따라 숨 멈춤) |
| 폐식 | 기도를 닫고 힘주어 숨 멈춤. 위험 |
| 태식 | 태아와 같은 숨. 단전·배꼽으로 쉬는 듯한 상태 |
| 봉고 | 수련 끝에 기를 단전에 묻어 닫음 |
| 심식상의 | 마음과 숨이 서로 의지 |
| 무타념 무타상 | 호흡하는 생각 외에 다른 생각을 하지 않음 |
| 축기 | 기초를 쌓음(백일축기) / 기를 쌓음 |
| 불씨(일양) | 단전에서 처음 일어나는 열 |
| 소주천 | 기가 독맥으로 올라 임맥으로 내려오는 한 바퀴 |
| 온양·목욕 | 막힌 곳에서 부드러운 기로 키우고 씻음 |
| 상기 | 기가 머리로 올라가 내려오지 않음 |
| 주화입마 | 기가 날뛰고 마음이 흔들리는 중증 부작용 |
