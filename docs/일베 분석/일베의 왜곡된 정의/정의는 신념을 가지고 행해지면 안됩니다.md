# 정의는 신념을 가지고 행해지면 안됩니다

정말 끔찍한 악은 자신이 하는 짓이 선이라고 ,정의라고 한점의 의심도 없이
믿고 자신만의 정의에 따라, 그에 조금이라도 어긋나는 사람들을 죄다
죽여야겠다고 생각하는 정의의 사도들입니다.역사상 광신의 이름으로 사람을
학살하는 광신도들은, 평소에는 친절하고 다정하며 온화하고 정의로운
사람들이였습니다. 정의는 신념에 의해 행해지면 안됩니다. 정의는 자신이
하는것이 과연 옳은가 문제는 없는가, 논리적으로 맞는가, 사실에 부합하는가
를 끊임없이 자문하면서 이루어져야 합니다.
