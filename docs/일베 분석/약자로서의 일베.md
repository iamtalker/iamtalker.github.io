# 약자로서의 일베

일베유저들은 그들이 가지는 폭력성과 가학성에도 불구하고 그럼에도 여전히
약자입니다. 비겁하고 비열하며 실패한 약자입니다. 강자를 감히 도모할
생각을 하지 못하는 겁쟁이입니다. 그들 말마따나 우리는 약자이고
장애인인데 왜 우리만 가지고 그러느냐 라고 말할만큼 약자입니다.

기득권의 유도에 따라 더 약한 사람들을,시스템을 개선하려는 사람들을
강자에게 대항하는 사람들을 부조리에 저항하는 사람들을 깔아뭉개면서 나는
더 이상 약자가 아니다 라고 자위하는 비겁한 약자인게 문제입니다.
