# 인간사회의 윤리

인간사회의 윤리라는것은 결국 인,어짐에서 출발한다.

어짐이라는것은 너와 나라고 하는 자아가 성립된 상태에서 서로 하나가
되려고 하는 이끌림이다.

의로움이라고 하는것은 어짐의 강제력이며 예절이라고 하는것은 어짐의
형상이며 법이라고 하는것은 의로움의 형상이다.

이런 순서대로 파고들어봤을때 과거 조선이 왜 그리 이상하게
치달았는가…생각해보면

인이 아니라 충이나 효를 국가 이념으로 삼았기 때문이다.

즉 인이 변해서 예가 되고 예가 변해서 충효가 나오는 것인데 앞뒤를
바꾸어서 생각하니 항상 오류가 발생하는게 당연하다.

왜 충이나 효를 국가이념으로 삼았나 추적해보면 그게 국가운영이 도움이
되기 때문이다.

서로 사랑하라 라는 가르침보다는 충성해라 라는 가르침이 국왕에게 도움이
되기 때문이다. 서로 사랑해라 라는 가르침보다는 윗사람에게 잘해라라는
가르침이 기존세력에게 도움이 되기 때문이지…
