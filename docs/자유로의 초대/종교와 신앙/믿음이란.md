# 믿음이란

기독교적인 것을 떠나서,…

믿음을 한마디로 정의하라면 바람을 버티는 큰돌 과도 같다.

바람이 불면 갈대는 바람에 맞춰 움직인다. 바람은 현실의 움직임이다.
갈대는 믿음이 없는 사람들의 마음이다.

자신의 마음을 잘 들여다보면, 마음이 현실에 맞추어서 영향받는다는것을
알수 있다.

그리고 자신이 마음 먹는다면 현실과는 무관하게 어떤 관점을 그대로
유지할수 있다는것도 알게 된다.

따라서 현실과는 무관하게 어떤 상황이 벌어지든지간에 특정한 관점을
유지할수 있다면 그것을 믿음이라고 부른다.

바람이 없을때는 모든 사람이 믿음을 유지하는것처럼 보인다. 그러나 바람이
태풍이 되면 비로서 누가 갈대이고 누가 반석인지 드러난다.

이건 기독교적인 믿음의 의미를 말하는게 아니다.

어떠한 현실적 변화에도 자신의 관점을 유지할수 있느냐 아니냐를
말하는것이다.
