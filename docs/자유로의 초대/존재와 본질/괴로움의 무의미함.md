# 괴로움의 무의미함

인간에게 있어 존재하는 모든것은 괴로움이다.

건강하지 못하면 괴롭고, 건강하면 건강이 나빠질까 봐 괴롭다. 애인이
없으면 괴롭고, 애인이 있으면 잃을까 봐 괴롭다. 돈이 없으면 괴롭고, 돈이
있으면 줄어들까 봐 괴롭다. 사는 것은 괴롭고, 죽음이 다가오면 죽을까 봐
괴롭다.

모든 존재가 괴로움이라는 것을 먼저 알아야 한다.그리고 존재의 결핍 또한
괴로움이라는 것을 깨달아야 한다.

이것은 마치 존재의 바다에서 밀물이 칠 때,그 파도 속에서 있음과 없음이
혼재되어 나타나며,형상의 존재와 결핍이 반복됨으로써 괴로움이 생기는 것과
같다.

그러나 밀물이 다하고, 썰물이 깊은 심해로 돌아가면 존재도, 존재의 결핍도,
존재와 존재의 결핍을 바라보는 자도 없다. 따라서 괴로움도 없다.

그런데 바다의 표면에 비하면 심해는 광대하다.존재하는 것에 비하면
존재하지 않는 것은 광대하다. 괴로움의 크기에 비하면 괴로움 없음은 더욱
광대하다.

그러므로 괴로움은 무의미하다. 자갈을 바다에 던진다고 해서 바다가 넘칠
수는 없다.
