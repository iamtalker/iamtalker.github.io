# 믿음의 시험

믿음과 신념과 결심은 항상 시험받는다

그건 이 세상이 시험을 좋아해서가 아니다

세상은 항상 변화하는 파도와 같은데

거기에 결심이 들어가면 그 변화하는 성질과

결심이 부딪쳐서 충돌이 일어나기 때문이다.

결심,믿음, 각오, 신념은 고정되어 있다. 세상은 고정되어 있지 않는
변화이다.

변화와 고정이 부딪칠때 사람들은 그것을 시험이라고 부른다.
