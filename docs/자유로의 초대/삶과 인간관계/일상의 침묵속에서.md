# 일상의 침묵속에서

뉴스를 보면 사람들은 절망한다. 왜냐면 뉴스는 항상
증오,슬픔,분노,광기,그리고 범죄를 다루니까.

그런데 만약 뉴스가 일상을 다룬다면 어떨까?? 예를 들어 옆집아저씨가 밥을
먹었니 뒷집 아줌마가 화장을 하고 장을 보러가니

그런 일상을 뉴스로 만들기 시작하면 범죄뉴스는 분명히 그대로 있을거지만,
일상뉴스에 매몰되어 버릴것이다.

대략 일상뉴스가 100만건이라면 범죄뉴스는 1건정도 되겠지.

그게 근데 현실이다. 오히려 신문,뉴스가 비현실이고. 왜냐면 일상과 범죄가
공존하는게 현실이지, 범죄만 있는게 현실이 아니기 때문이다.

여기서 더 나아가서 일상의 근본에 있는 침묵에 대해서 여백에 대해서
지켜보기시작하면 인간의 고통이나 괴로움,사건사고는 더 엄청난 비율로
축소된다.

구체적으로 말하자면 조용하고 어두운 방에 홀로 앉아 무엇을 하려 하지도
않고 조용히 내면의 침묵을 바라본다면..

결국 인간은 망망한 우주에 서서 한톨의 먼지같은 사건사고에 매달려
있었음을 알게된다.

그때가 되면 오히려 하늘로 떠버리지 않기 위해 어떤 문제의식이 필요하고,
너무 가볍기 때문에 고민이 있어야 한다는 말을 이해할수 있게 될것이다.
