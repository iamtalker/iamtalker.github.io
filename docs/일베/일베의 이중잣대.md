# 일베의 이중잣대

일베유저의 이중잣대가 진짜 웃긴게… 까고 보니 전라도 알고 보니 김치녀
라고 하면서 한 사람의 일베유저가 잘못한것을 가지고 전체 일베유저를
욕하지 말라?

까고 보니 전라도라는 라벨링을 하는 게 일베인인데 그 일베인한테
라벨링해서 일베 전체를 욕하는 게 안된다니 이건 무슨 이지스의 철벽 논리
방패죠. 만물 홍어설을 할 때는 괜찮고 자기가 만물 일베설로 왕따 당하면
부당하다는 논리도 아니고 이건 뭐 자기로맨남불륜설인가여
